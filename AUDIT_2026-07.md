## П1 / П1а — TELEGRAM FORWARDER: причина простоя

Гипотеза "нерезолвленный entity" — НЕ ПОДТВЕРДИЛАСЬ. Все 7 каналов
резолвятся через get_entity() без ошибок.

РЕАЛЬНАЯ ПРИЧИНА: аккаунт форвардера физически не состоит ни в одном
из 7 целевых каналов — их нет в iter_dialogs(). Telethon
events.NewMessage требует членства в диалоге для push-событий,
резолва по username недостаточно.

В диалогах аккаунта — только старые джоб-каналы от предыдущей версии
бота. SOURCES обновили при смене фокуса, подписку аккаунта — нет.

Побочный баг: last_id в buffer_reader() не персистится — дубликат-шум
в логах при каждом рестарте.

Требует решения: подписать аккаунт на 7 каналов.

Подтверждено на уровне кода (П6/РЧ4): forwarder.py — архитектура
двухступенчатая (не описана нигде в документации). Two-layer
дедупликация работает.
